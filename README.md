# Jajce Website

A responsive React website showcasing the most beautiful landmarks of Jajce, Bosnia and Herzegovina.  
Built with **React**, **Swiper.js**, and **React Router**.

## 🛠️ Built With
- [React](https://react.dev/)
- [React Router](https://reactrouter.com/)
- [Swiper.js](https://swiperjs.com/)
- [Vite](https://vitejs.dev/)
- [React Leaflet](https://react-leaflet.js.org/)
