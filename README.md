# Jajce Website

A responsive React website showcasing the most beautiful landmarks of Jajce, Bosnia and Herzegovina.  
Built with **React**, **Swiper.js**, and **React Router**.

## 🛠️ Built With
- [React](https://react.dev/)
- [React Router](https://reactrouter.com/)
- [Swiper.js](https://swiperjs.com/)
- [Vite](https://vitejs.dev/)
- [React Leaflet](https://react-leaflet.js.org/)

## Installation
  ### Clone the repository
  git clone https://github.com/Da4078/jajce-website.git
 ### Navigate to the project folder
  ```bash 
  cd jajce-website
```

### Clone the repository
```bash
git clone https://github.com/Da4078/jajce-website.git
```
  ### Install all dependencies
```bash
npm install react@^18.3.1 react-dom@^18.3.1 react-router-dom@^6.30.1 react-i18next@^16.3.5 swiper@^12 react-id-swiper@^4.0.0 leaflet@^1.9.3 react-leaflet@^4.2.0 react-leaflet-cluster@^2.1.0
```
  ### Start the development server
  ```bash
npm run dev
```
